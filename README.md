# Lyricrodin

Puente experimental para sincronizar letras de YouTube Music con HyperLyrics Enhanced mediante Lyricon y LRCLIB en HyperOS 4.

**Estado:** código experimental, sin compatibilidad garantizada con la ROM de oz7wm.

Requisitos: Android 17, HyperLyrics Enhanced con Lyricon Central, acceso a notificaciones para leer MediaSession de YouTube Music.

La compilación debug se realiza con GitHub Actions y el APK firmado de prueba se entrega como artefacto de cada ejecución.
